Quiz App-"QuizWhiz".
An interactive Quiz Application that allows users to test their knowledge through multiple-choice questions with instant feedback.
The quiz are dynamically generate with the help of Gemini API.
The scores are used to store in the DB and shows on the "LeaderBoard" page.
#Features-
Multiple-choice questions,
Different subjects (E.g. Java, python, etc.),
Instant answer validation,
Score tracking,
Clean and responsive UI.
#Tech Stack-
React.js,
Tailwind CSS,
Express.js,
MongoDB Atlas.
